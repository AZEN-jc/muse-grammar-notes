# 动词

## 动词四大分类

- **实义动词**：有完整词义，可单独作谓语
- **系动词**：词义不完整，后接==表语==
- **助动词**：无实际意义，辅助构成时态语态
- **情态动词**：表语气态度，后接动词原形

### 及物动词（`vt.`）vs 不及物动词（`vi.`）

| 类别 | 语法特征 | 高频代表词 | 典型例句 |
| :--- | :--- | :--- | :--- |
| 及物动词 (`vt.`) | 词义完整，直接跟==宾语== | `do`, `cost`, `love`, `read`, `like`, `watch`, `see` | `I teach you.` |
| 不及物动词 (`vi.`) | 不可直接跟宾语；接宾语须加==介词== | `go`, `come`, `leave`, `listen`, `arrive`, `stay`, `live`, `talk`, `die`, `happen`, `appear` | `I go to the park.` / `They laugh at him.` / `She is talking with her mother.` |

> [!why] 底层逻辑
> 为什么“看/听/笑”常要加介词？因为 `look`（看）、`listen`（听）、`laugh`（笑）本身只强调==动作发出==，不自带动作承受对象，必须借助介词（`look at`, `listen to`, `laugh at`）才能把动作引向宾语。

## 系动词与情态动词

### 系动词（Link Verbs）六大类

- **核心结构**：`主语 + 系动词 + ==表语==`

| 分类 | 核心词汇 | 用法与典型例句 |
| :--- | :--- | :--- |
| `be` 动词类 | `am`, `is`, `are`, `was`, `were` | 最基础系动词，连接主语与身份/状态 |
| 感官类（……起来） | `look`, `sound`, `smell`, `taste`, `feel` | 后接==形容词==作表语：`The rose smells sweet.` |
| 变化类（变） | `become`, `get`, `go`, `turn`, `grow`, `come`, `fall` | 侧重状态转变（详见下方“变”字辨析表） |
| 保持类（保持） | `keep`, `remain`, `stay` | `keep quiet` / `remain unchanged` / `Stay calm.` |
| 表象类（似乎） | `seem`, `appear` | 后常接 `(to be)`：`seem` 侧重主观感受，`appear` 侧重外表表象 |
| 结果证明类 | `prove`, `turn out (to be)` | `The handbook proved most useful.` / `His plan turned out to be a success.` |

#### 高频“变”字系动词精准辨析

| 动词 | 侧重方向 | 常见搭配 / 例句 |
| :--- | :--- | :--- |
| `become` | 中性通用，多指身份、职位或状态变化 | `become friends` / `become a teacher` |
| `get` | 强调==渐变过程==，常接形容词比较级 | `get busier` / `get older` / `get dark` |
| `go` | 多指由好变坏（==往坏处变==），`go hungry` 除外 | `go bad` / `go mad` / `go sour` / `go hungry` |
| `turn` | 强调==颜色==或性质的明显改变 | `turn yellow` / `turn red` |
| `grow` | 强调==逐渐成长==或自然而然的缓慢变化 | `grow old` / `grow tall` / `grow dark` |
| `come` | 多指==向好==的方面变化或梦想实现 | `come true` / `come right` |
| `fall` | 多用于固定搭配，表进入某种状态 | `fall asleep` / `fall ill` |

> [!trap] 易错对比：系动词 vs 实义动词
> - `You look ==happy==.`（`look` 为系动词“看起来”，后接==形容词==作表语，构成==主系表==）
> - `You look at the gift ==happily==.`（`look` 为实义动词“看”，需用==副词==修饰动作，构成==主谓宾==）
> - 口诀：**形修名（或作表语），副修动**。

### 助动词（Auxiliary Verbs）四大类

- **核心特征**：无实际词义，不能单独作谓语

| 助动词家族 | 包含词形 | 核心语法功能 |
| :--- | :--- | :--- |
| `do` 类 | `do`, `does`, `did` | 助实义动词构成==否定句==与==疑问句==（后续动词还原为原形） |
| `will` 类 | `will`, `shall`, `would`, `should` | `+ 动词原形` 构成==一般将来时== / 过去将来时 |
| `have` 类 | `have`, `has`, `had` | `+ 过去分词` 构成==完成时态== |
| `be` 类 | `am`, `is`, `are`, `was`, `were` | `+ v-ing` 构成==进行时==；`+ 过去分词` 构成==被动语态== |

### 情态动词（Modal Verbs）

- **待补充**：情态动词专章暂未收录

## 动词基本形式与不规则变化

### 动词五种基本形式总览

| 原形 | 第三人称单数 | 过去式 | 现在分词 | 过去分词 |
| :--- | :--- | :--- | :--- | :--- |
| `do` | `does` | `did` | `doing` | `done` |
| `be` | `is` | `was / were` | `being` | `been` |

### 第三人称单数变化规则

- **使用前提**：一般现在时中，主语为第三人称单数时使用

| 变化规则 | 核心操作 | 高频例词 |
| :--- | :--- | :--- |
| 一般情况 | 词尾直接加 ==-s== | `treat → treats` |
| `s / x / sh / ch` 及部分 `o` 结尾 | 词尾加 ==-es== | `finish → finishes`, `do → does` |
| 辅音字母 + `y` 结尾 | 变 `y` 为 `i` 加 ==-es== | `carry → carries` |
| 元音字母 + `y` 结尾 | 直接加 ==-s== | `play → plays` |
| 不规则变化 | 特殊词形 | `have → ==has==` |

### 过去式与过去分词规则变化

- **过去式**：作==谓语动词==，表示过去发生的动作
- **过去分词**：作==非谓语==或构成被动/完成时态

> [!formula] 过去分词核心功能
> - `be + 过去分词` → 构成==被动语态==（`The children are well looked after.`）
> - `have / has / had + 过去分词` → 构成==完成时态==

| 规则类别 | 核心操作 | 高频例词 |
| :--- | :--- | :--- |
| 一般情况 | 词尾直接加 ==-ed== | `lock → locked`, `shout → shouted`, `wash → washed`, `work → worked`, `cheat → cheated`, `elect → elected`, `visit → visited`, `snow → snowed` |
| 不发音 `-e` 结尾 | 词尾直接加 ==-d== | `close → closed`, `like → liked`, `live → lived`, `smile → smiled`, `bake → baked`, `describe → described` |
| 辅音字母 + `y` 结尾 | 变 `y` 为 `i` 加 ==-ed== | `study → studied`, `supply → supplied`, `copy → copied` |
| 元音字母 + `y` 结尾 | 直接加 ==-ed== | `enjoy → enjoyed`, `play → played`, `stay → stayed` |
| 重读闭音节（辅元辅） | 双写尾字母加 ==-ed== | `stop → ==stopped==`, `admit → ==admitted==`, `refer → ==referred==`, `prefer → ==preferred==`, `plan → ==planned==` |

### 不规则动词分类记忆表

| 变化类型 | 变化规律 | 高频不规则动词（原形 - 过去式 - 过去分词） |
| :--- | :--- | :--- |
| `A-A-A` 型 | 三形完全相同 | `hit - hit - hit`, `burst - burst - burst`, `cut - cut - cut`, `put - put - put`, `set - set - set`, `cost - cost - cost` |
| `A-B-B` 型 | 过去式与过去分词同形 | `spend - spent - spent`, `make - made - made`, `bring - brought - brought`, `buy - bought - bought`, `get - got - got`, `lend - lent - lent`, `keep - kept - kept`, `stand - stood - stood`, `think - thought - thought`, `feel - felt - felt`, `find - found - found`, `hear - heard - heard`, `leave - left - left` |
| `A-B-C` 型 | 三形各不相同 | `wake - woke - ==woken==`, `swim - swam - swum`, `do - did - done`, `take - took - taken`, `drive - drove - driven`, `give - gave - given`, `fall - fell - fallen`, `go - went - gone`, `begin - began - begun` |
| `A-B-A` 型 | 原形与过去分词同形 | `become - became - become`, `run - ran - run`, `come - came - come` |

### 动词的 `-ing` 形式

- **构成时态**：`be + v-ing` 构成==进行时态==
- **构成动名词**：作主语、宾语或表语
- **构成现在分词**：作定语、状语或补语

| 变化规则 | 核心操作 | 高频例词 |
| :--- | :--- | :--- |
| 一般情况 | 直接加 ==-ing== | `check → checking`, `help → helping` |
| 不发音 `-e` 结尾 | 去 `e` 加 ==-ing== | `move → moving` |
| 双 `ee` 结尾 | 直接加 ==-ing== | `agree → agreeing` |
| 重读闭音节（辅元辅） | 双写尾字母加 ==-ing== | `stop → ==stopping==`, `chat → ==chatting==`, `drop → ==dropping==` |
| `-x` 结尾 / 非重读闭音节 | 直接加 ==-ing==（不双写） | `relax → relaxing`, `visit → visiting` |
| `ie` 结尾 | 改 `ie` 为 `y` 再加 ==-ing== | `die → ==dying==`, `tie → ==tying==`, `lie → ==lying==` |

## 延续性动词与非延续性动词

| 分类 | 语法特征 | 高频代表词 | 典型例句 |
| :--- | :--- | :--- | :--- |
| 延续性动词 | 动作可持续，==可==与时间段连用 | `study`, `work`, `read`, `sleep`, `learn`, `stay`, `keep`, `have`, `wait` | `I have been waiting for you for two hours.` |
| 非延续性动词（短暂性） | 动作瞬间完成，==不可==与时间段连用 | `go`, `come`, `begin`, `leave`, `arrive`, `die`, `open`, `finish` | `I finished my homework just now.` |

> [!why] 底层逻辑：为什么非延续性动词不能直接搭 `for + 时间段`？
> `finish`（完成）、`die`（死亡）、`leave`（离开）在英语逻辑里是一个“时间点”上的瞬间开关——按下去动作就结束了，根本没有“持续过程”。因此不能说“我已经完成了两个小时”，必须换成表示==持续状态==的延续性动词（如 `keep` 代替 `borrow`，`be away` 代替 `leave`，`be dead` 代替 `die`）才能与 `for + 时间段` 连用。

> [!trap] 高频易错点
> 瞬间动作不能直接搭 `for + 时间段`。如不能说 `I have finished it for two hours`，要改用延续性表达或 `just now` 等时间点。

> [!mnemonic] 感官/使役动词与非延续性转化口诀
> - **一感二听三让四看**：`feel` / `hear, listen to` / `make, let, have` / `see, watch, notice, look at` 后接省略 `to` 的不定式（主动省 `to`，被动还原 `to`）。
> - **瞬间变延续常用替身**：`borrow → ==keep==`、`buy → ==have==`、`leave → ==be away==`、`die → ==be dead==`、`join → ==be in==`、`begin → ==be on==`。
