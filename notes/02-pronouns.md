# 代词

## 人称、物主与反身代词

- **代词定义**：代替名词及起名词作用的短语或句子的词
- **主格与宾格**：主格作==主语==（谓语前）；宾格作==宾语==（动/介后）
- **物主代词口诀**：==有名则形，无名则名==
- **反身代词规则**：不作主语或定语；主宾同人时使用

### 三类代词完整矩阵

| 人称与数 | 人称代词（主格 / 宾格） | 形容词性物主代词 | 名词性物主代词 | 反身代词 |
| :--- | :--- | :--- | :--- | :--- |
| 第一人称单数 | `I` / `me` | `my` | `mine` | `myself` |
| 第二人称单数 | `you` / `you` | `your` | `yours` | `yourself` |
| 第三人称单数 | `he/she/it` / `him/her/it` | `his/her/its` | `his/hers/its` | `himself/herself/itself` |
| 第一人称复数 | `we` / `us` | `our` | `ours` | `ourselves` |
| 第二人称复数 | `you` / `you` | `your` | `yours` | `yourselves` |
| 第三人称复数 | `they` / `them` | `their` | `theirs` | `themselves` |

> [!why] 底层逻辑：什么是“有名则形，无名则名”？
> 形容词性物主代词（如 `my`）本质上相当于限定词，必须跟名词才能站稳（`my bike`）；名词性物主代词（如 `mine`）等于“形容词性物主代词 + 名词”，自身已经打包了名词，所以后面绝不能再接名词（`That car is mine`）。

## 指示代词与疑问代词

- **基本词**：`this`, `that`, `these`, `those`

### 替代词辨析：`that` vs `those` vs `the one` vs `it`

| 替代词 | 指代对象与范围 | 同物 vs 同类 | 高频例句 |
| :--- | :--- | :--- | :--- |
| `it` | 特指上文提到的==同一个==事物 | 同物同类 | I have a cat. ==It== is very cute. |
| `one` | 泛指上文提到的同类==单数可数==名词 | 同类不同物 | My cat needs a friend. I want to buy ==one==. |
| `the one` | 特指上文 `the + 单数可数名词` | 同类不同物（特指） | The book bought yesterday is better than ==the one== borrowed from the library. |
| `that` | 特指上文 `the + 单数可数/不可数名词` | 同类不同物（特指） | The population of SH is smaller than ==that== of ZZ. |
| `those` | 特指上文 `the + 复数可数名词` | 同类不同物（特指） | The apples on this tree are bigger than ==those== on that tree. |

> [!trap] 考试易错坑：`the one` 不能替代不可数名词
> `the one` 只能替代 `the + 可数名词单数`，遇到不可数名词（如 `population`、`weather`、`water`）或抽象名词作比较时，必须用 ==that==，绝对不能用 `the one`。

## 不定代词核心辨析

### 数量范围矩阵：`all / none / both / either / neither`

| 不定代词 | 适用数量 | 肯定 / 否定 | 主谓一致与常用搭配 |
| :--- | :--- | :--- | :--- |
| `all (of)` | ==三者及以上== | 肯定（都） | `All of us agree`（接复数谓语复数） |
| `none (of)` | ==三者及以上== | 否定（都不） | `None of us agrees/agree`（单复数均可） |
| `both (of)` | ==两者== | 肯定（两个都） | `both ... and ...`（谓语用复数） |
| `either (of)` | ==两者== | 肯定（两者任一） | `either ... or ...`（就近原则；`either of` 谓语用==单数==） |
| `neither (of)` | ==两者== | 否定（两个都不） | `neither ... nor ...`（就近原则；`neither of` 谓语用==单数==） |

> [!trap] 考试易错坑：隐含的“2”与转折词 `but`
> 做题时注意题目中隐含数量为 2 的名词，如 `parents`（父母）、`twins`（双胞胎）、`couple`（夫妻）；同时留意句中的转折词 `but`，避免把“两者都不”误选成“三者都不”。

### `each` 与 `every` 的区别

- **范围**：`each` ≥ 2；`every` ≥ 3
- **词性**：`each` 作代/形；`every` 仅作==形容词==
- **间隔表达**：`every + 基数词 + 复数`

间隔表达等价形式：`every two days` = `every second day` = `every other day`（每隔一天）。

> [!trap] 考试易错坑：没有 `every of`
> 因为 `every` 只能作形容词、不能作代词，所以英语里只有 ✅ `each of us`，绝不存在 ❌ `every of us`。

### `other / others / the other / the others / another`

| 词形 | 语法功能与范围 | 核心公式 / 例句 |
| :--- | :--- | :--- |
| `other` | adj. 其他的（无特指、无范围） | `some other + 单/复数`；==any other + 名词单数==；`all the other + 复数` |
| `others` | 代词，`= other + 复数名词`（泛指） | `some ... others ...`（Some are red and ==others== are blue.） |
| `the other` | `the other + 单数`（两者中的另一个） | One is blue and ==the other== is yellow. |
| `the other + 复数` | 剩余的全部（`= the others`） | `some ... the others ...`（Some are red and ==the others== are blue.） |
| `another` | 泛指“另一个”（无范围）；或表“再几个” | `another + 单数` / `another + 基数词 (>1) + 复数`（`= 基数词 + more + 复数`） |

> [!mnemonic] 不定代词高频辨析口诀
> - **有无 `a` 定肯否**：`a few / a little` 有 `a` 表==肯定==（有一点），`few / little` 无 `a` 表==否定==（几乎没有）；`few` 接可数复数，`little` 接不可数。
> - **特指泛指看 `the`**：两者剩余用 `the other`，三者以上另选一个用 `another`，复数代词末尾加 `s`（`others / the others`）。

### `some` 与 `any` 辨析

| 词形 | 适用句型与含义 | 高频例句 |
| :--- | :--- | :--- |
| `some` | 肯定句“一些”；委婉请求/希望得到肯定回答的疑问句；表“某个” | `I have some story books.` / `Would you like some coffee?` / `Someone is knocking.` |
| `any` | 否定/疑问句“一些”（接不可数或复数）；肯定句“==任一==”（接单数） | `I don't have any pens.` / `Do you have any pens?` |

### 相互代词与复合不定代词

| 类别 | 核心词形 | 语法规则 / 固定搭配 |
| :--- | :--- | :--- |
| 相互代词 | `each other`（传统指两者）, `one another`（三者以上） | 所有格：`each other's`, `one another's`；放动词后，==不作主语== |
| 复合不定代词（物） | `something`, `anything`, `everything`, `nothing` | 作主语谓语用==单数==；`anything` 多用于否定/疑问句 |
| 复合不定代词（人） | `someone/somebody`, `anyone/anybody`, `everyone/everybody`, `nobody` | 定语后置：`复合不定代词 + ==形容词==`（`something important`） |
| 高频短语 | `anything but`（决不，根本不） / `nothing but`（只有，仅仅） | `The problem is anything but easy.` / `It is nothing but a joke.` |

## It 核心句型（形式主语与形式宾语）

- **指代功能**：指代婴儿、未知性别、天气时间距离
- **形式主语**：用 `it` 占主语位，真正主语后置
- **形式宾语**：常见于 `think / find` 后

常用形式宾语触发动词：`think`, `believe`, `find`, `feel`, `consider`, `make`。

> [!formula] It 核心句型公式
> - 一般形式主语：`It is/was + adj./n. + ==to do== sth.`
> - 评价事情本身：`It is + adj. + ==for== sb. + to do sth.`
> - 评价人的品质：`It is + adj. + ==of== sb. + to do sth.`
> - 花费时间：`It takes/took/will take sb. + 时间 + ==to do== sth.`
> - 形式宾语：`sb. + think/believe/find/feel/consider/make + ==it== + adj./n. + to do sth.`

> [!why] 底层逻辑：为什么有时用 for，有时用 of？
> 看形容词究竟在夸/骂「事」还是在夸/骂「人」。说 `difficult / important / necessary` 时，难或重要的是“做这件事”而不是人，所以用 `for sb.`（对某人来说）；说 `kind / foolish / careless` 时，善良或愚蠢的是“这个人本身”，可以还原成 `sb. is foolish to do...`，所以用 `of sb.`。

| 结构类型 | 常见触发形容词 / 动词 | 高频例句 |
| :--- | :--- | :--- |
| `for sb.`（饰事） | easy, difficult, hard, necessary, important, possible, impossible, obvious, useful, useless, dangerous | It is very difficult ==for== me to finish the task on time. |
| `of sb.`（饰人） | kind, nice, rude, cruel, careless, foolish, stupid, wise, crazy | It is very foolish ==of== you to believe his words. |
| 花费时间 | takes / took / will take | It took me three days ==to paint== the house. |

> [!trap] 考试易错坑：形式主语与形式宾语只能用 `it`
> 改错与填空题常把形式主语/宾语 `it` 偷换成 `that` 或 `this`，也常漏掉不定式符号 `to`：
> - ❌ I think **that** important to learn English well.
> - ✅ I think **it** important to learn English well.

## 顺带拓展短语

| 短语 | 释义 | 例句 / 备注 |
| :--- | :--- | :--- |
| It is time to do sth. | 是时候做某事了 | It is time to go to bed. |
| I would appreciate it if ... | 如果……我将不胜感激 | I would appreciate it if you could help me. |
| take it for granted that ... | 认为……是理所当然的 | Don't take it for granted that parents should do everything for you. |
| take it easy | 放轻松 | Take it easy, you still have time. |
| take it seriously | 严肃认真对待 | You should take this exam seriously. |
| make it | 成功做到；赶上 | Keep trying and you will make it! |
