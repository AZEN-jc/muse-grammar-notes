# 数词

## 基数词与序数词

- **基数词**：表数目（`zero`, `one`, `two`...）
- **序数词**：表顺序（`first`, `second`...）
- **百位读法**：百位与十/个位间加 ==and==

### 基数词拼写速览

| 数值范围 | 常见词汇 | 拼写注意 |
| :--- | :--- | :--- |
| `0 ~ 12` | `zero`, `one` ~ `twelve` | 独立词形，注意 `ten`, `eleven`, `twelve` |
| `13 ~ 19` | `thirteen` ~ `nineteen` | 词尾 `-teen`，注意 `thirteen`, `fifteen`, `eighteen` |
| 整十 (`20 ~ 90`) | `twenty` ~ `ninety` | 词尾 `-ty`，注意 `twenty`, `thirty`, ==forty==, `fifty`, `eighty` |

### 基数词变序数词规则

| 变化规律 | 核心规则 | 高频例词 |
| :--- | :--- | :--- |
| 前三单独记 | 独立变化，其余加 `-th` | `first`, `second`, `third`, `fourth` |
| 八去 `t`，九去 `e` | 去掉末尾字母再加 `-th` | `eight → ==eighth==`, `nine → ==ninth==` |
| `ve` 要用 `f` 替 | `ve → f` 再加 `-th` | `five → ==fifth==`, `twelve → ==twelfth==` |
| 整十变 `tie` | `ty → tie` 再加 `-th` | `twenty → twentieth`, `thirty → thirtieth` |
| 两位数以上 | 十位基数、个位序数 | `twenty-one → twenty-first` |

> [!mnemonic] 记忆口诀：基变序
> 基变序，有规律，词尾加上 `-th`；一二三，特殊记，词尾字母 `t, d, d`；八去 `t`，九去 `e`，`ve` 要用 `f` 替；见 `y` 变成 `i` 和 `e`，词尾再加 `-th`；若是遇到几十几，只变个位就可以。

### 序数词前用 `the` 还是 `a/an`？

| 冠词搭配 | 含义 | 高频例句 |
| :--- | :--- | :--- |
| `the + 序数词` | 表示顺序“第几” | I am ==the first== to go to school. |
| `a / an + 序数词` | 表示==“再一，又一”==（不强调排名） | I want to try ==a second== time.（我想再试一次） |

> [!why] 底层逻辑：为什么序数词前有时加 `a/an`？
> 加 `the` 是把事物放在队列里数“第 1、第 2 个”（特指唯一位置）；加 `a/an` 则不看排名，只表示在前一次基础上“再来一个/又一次”（如 `a second time` = `another time`）。

## 分数、小数与百分数

### 分数表达公式与主谓一致

> [!formula] 分数表达公式
> `==分子用基数词==，==分母用序数词==；分子大于 1，分母加 -s`

| 数值 | 标准英文表达 | 备注 |
| :--- | :--- | :--- |
| `1/3` | `one third` | 分子为 1，分母不加 `s` |
| `2/5` | `two ==fifths==` | 分子大于 1，分母加 `s` |
| `1/2` | `one half` = `a half` | 固定特殊表达 |
| `1/4` | `a quarter` = `one fourth` | `quarter` 表“四分之一” |
| `3/4` | `three quarters` | 分子大于 1，`quarters` 加 `s` |

### 小数与百分数

| 类型 | 构成公式 | 示例与主谓一致 |
| :--- | :--- | :--- |
| 小数 | `基数词 + point + 基数词` | `5.3` → `five point three` |
| 百分数 | `基数词 + percent` | `80%` → `eighty percent` |

> [!trap] 考试易错坑：分数/百分数作主语的主谓一致
> `分数 / 百分数 + of + 名词` 作主语时，谓语动词单复数**由 `of` 后面的名词决定**（与前面的数字无关）：
> - ✅ Two thirds of the students ==are== girls.（`students` 复数 → `are`）
> - ✅ Eighty percent of the water ==is== polluted.（`water` 不可数 → `is`）

## 时间、日期与年龄表达

| 表达场景 | 固定结构 | 高频例句与翻译 |
| :--- | :--- | :--- |
| 某人几十多岁 | `in one's + 整十基数词复数` | She became a famous star ==in her thirties==.（三十多岁） |
| 具体某岁时 | `at the age of + 基数词` | He left school at the age of 18. |
| 某世纪某年代 | `in the + 年份复数 / 所有格` | `in the 1820s` / `in the 1820's`（在 19 世纪 20 年代） |
| 具体某一年 | `in + 年份` | `in 1820`（在 1820 年） |

> [!trap] 考试易错坑：`in the 1820s` 不是“1820 年”
> `in 1820` 指具体某一年；加了 `the` 和复数 `-s`（`in the 1820s`）表示“19 世纪 20 年代”（即 1820~1829 年）。

## 高频考点与固定搭配

### 确数与概数（`hundred / thousand / dozen / score`）

- **确数用单数**：具体数字 + 单位词单数
- **概数用复数**：单位词加 ==-s== 后与 ==of== 连用

| 单位词 | 含义 | 确数示例（不加 `s`） | 概数示例（加 `s` + `of`） |
| :--- | :--- | :--- | :--- |
| `hundred` | 百 | `two hundred people` | `hundreds of people`（成百上千人） |
| `thousand / million / billion` | 千 / 百万 / 十亿 | `five million` | `millions of`（数百万的） |
| `dozen` | 一打（12 个） | `three dozen bottles of milk`（36 瓶） | `dozens of ==times==`（许多次） |
| `score` | 二十（20） | `two score and four years`（44 年） | `scores of`（许多） |

### 编号、复合形容词、频率与 `the/a number of`

| 考点 | 核心规则 / 公式 | 高频例句 |
| :--- | :--- | :--- |
| 编号表达 | `名词（首字母大写）+ 基数词` = `the + 序数词 + 名词` | `Page 7 (P.7)`, `Room 606` |
| 复合形容词 | `基数词 + 连字符 + ==单数名词==` | `a five-year-old girl`（一个 5 岁的女孩） |
| 间隔表达 | `every + 基数词 + 复数` = `every + 序数词 + 单数` | `every two weeks` = `every second week`（每两周） |
| 频率与倍数 | 一次 `once`，两次 `twice`，三次及以上 `基数词 + times` | `once a day`（一天一次）, `three times` |
| `a number of` | 许多的 + 可数复数，谓语用==复数== | A number of students ==like== Xiao Zhan. |
| `the number of` | ……的数量 + 可数复数，谓语用==单数== | The number of the students ==is== twenty. |
| `an / the amount of` | `an amount of`（大量）vs `the amount of`（……的量） | 后接==不可数名词== |
