# 形容词与副词

## 形容词的定义与语法功能

- **形容词**：说明人或事物==特征、性质、状态==的词
- **修饰对象**：主要修饰==名词或代词==，译为“……的”
- **四种语法功能**：前置定语、后置定语、宾语补足语、表语

| 语法功能 | 位置 | 例句 |
| :--- | :--- | :--- |
| 前置定语 | 名词之前 | She is a ==beautiful== girl. |
| 后置定语 | 被修饰词之后 | I have something ==important== to tell you. |
| 宾语补足语 | 宾语之后，补足宾语状态 | That gift will make you ==happy==. |
| 表语 | 系动词之后 | She is ==beautiful==. |

> [!why] 底层逻辑：为什么形容词有四种位置？
> 前置定语是常态（先给名词“贴标签”再说它是谁）；后置定语是“被迫后置”——被修饰的是 something 这类复合不定代词时，形容词没地方插，只能跟在后面；宾语补足语是“使宾语处于某种状态”（make you happy = 让你变得高兴）；表语是系动词后的状态说明（she is beautiful = 她处于“美丽”这个状态）。

### 多个形容词作定语的顺序

- **顺序口诀**：==限—观—形—龄—颜—国—材==
- **限定词**：a/an、this/that、my、some
- **观点**：beautiful（主观评价）
- **形状**：large、long
- **年龄**：new、old
- **颜色**：red
- **国籍**：Chinese
- **材料**：glass、wooden

> [!mnemonic] 记忆口诀：限观形龄颜国材
> 限定词打头，观点第二，形状、年龄、颜色、国籍、材料依次排。记住“限观形龄颜国材”七个字，多个形容词叠在一起就不会排错。

## 形容词的后置定语

- **后置定语**：形容词放在被修饰词之后
- **触发情形**：复合不定代词、a- 开头形容词
- **触发情形**：词义变化、介词短语

### 修饰复合不定代词时后置

- **规则**：形容词必须放在这类代词==之后==

复合不定代词：something、somebody、someone、anything、everything。

例句：I have something ==important== to tell you.

### 以 a- 开头的形容词后置

- **规则**：这类形容词只能作==后置定语或表语==，不能前置
- **例句**：the students ==awake==（醒着的同学）

常见词：asleep（睡着的）、alike（相似的）、alone、awake、alive。

> [!why] 底层逻辑：为什么 a- 开头的形容词只能后置？
> asleep、alive 这类词历史上是“on sleep”“in life”这类介词短语缩合而成的，本质上是“处于某种状态”的表语残留。它们天生是“谓语性”的，站在名词前面会很别扭，只能跟在名词后面或系动词后面。

### present 与 absent：前后置词义不同

| 形容词 | 前置含义与例句 | 后置含义与例句 |
| :--- | :--- | :--- |
| present | 目前的：the ==present== situation（目前的情况） | 在场的：the students ==present==（在场的学生） |
| absent | 缺席的：an ==absent== student（缺席的学生） | 不在场的：student ==absent== from class（缺课的学生） |

### 介词短语与定语从句作后置定语

- **定语从句后置**：定语从句作定语时，一般后置

介词短语后置：the apple ==on the table==（桌子上的苹果）。

## 常用形容词后缀

| 后缀 | 构成方式 | 例词 |
| :--- | :--- | :--- |
| -y | 名词 + y | windy（有风的）、rainy（下雨的）、snowy（下雪的） |
| -ful | 名词 + ful | powerful（有权力的）、useful（有用的）、successful（成功的）、wonderful（极好的） |
| -al / -ial | 名词 + al 或 ial | personal（私人的）、natural（自然的，nature → natural） |
| -ous / -ious | 名词 + ous 或 ious | dangerous（危险的，danger → dangerous）、ambitious（有抱负的，ambition → ambitious）、poisonous（有毒的，poison → poisonous） |
| -ish | 名词 + ish | foolish（愚蠢的）、selfish（自私的）、childish（孩子气的） |
| -able / -ible | 名词或动词 + able 或 ible | fashionable（流行的）、comfortable（舒服的）、reasonable（合情合理的，reason → reasonable） |
| -ive / -ative | 动词或名词 + ive 或 ative | attractive（有吸引力的，attract → attractive）、instructive（有教育意义，instruct → instructive）、effective（有效的，effect → effective） |
| -ical | 名词 + ical | practical（实际的，practice → practical） |

> [!why] 底层逻辑：后缀不是死记的，是“转性”的开关
> 后缀的作用是把一个词“转性”成形容词：-ful 是“充满……”（useful = 充满用处）、-ous 是“具有……性质”（dangerous = 具有危险性）、-able 是“能够被……”（comfortable 本义是“能被安慰的”→舒服的）。先认后缀的意思，再猜生词词义，八九不离十。

## -ing 与 -ed 形容词辨析

- **-ing**：让别人==感到……==（主动发出感受）
- **-ed**：自己==感到……==（被动承受感受）

| 动词 | -ing（令人……） | -ed（感到……） |
| :--- | :--- | :--- |
| bore | boring（令人无聊的） | bored（感到无聊的） |
| amaze | amazing（令人惊奇的） | amazed（感到惊奇的） |
| excite | exciting（令人兴奋的） | excited（感到兴奋的） |
| surprise | surprising（令人惊讶的） | surprised（感到惊讶的） |
| move | moving（令人感动的） | moved（感动的） |
| inspire | inspiring（鼓舞人心的） | inspired（受到鼓舞的） |
| encourage | encouraging（令人鼓舞的） | encouraged（受到鼓舞的） |
| confuse | confusing（令人困惑的） | confused（感到困惑的） |
| frighten | frightening（吓人的） | frightened（感到害怕的） |
| embarrass | embarrassing（令人尴尬的） | embarrassed（感到尴尬的） |
| annoy | annoying（令人讨厌的） | annoyed（感到讨厌的） |
| relax | relaxing（令人放松的） | relaxed（感到放松的） |

> [!why] 底层逻辑：-ing 是“发出”，-ed 是“承受”
> -ing 是现在分词，表主动、进行：the movie is boring = 电影正在“发出无聊”；-ed 是过去分词，表被动、完成：I am bored = 我“承受了无聊”。判断主语是“发出者”还是“承受者”，-ing/-ed 就不会选错。

> [!trap] 考试易错坑：修饰人时 -ing 和 -ed 最容易混
> - ❌ I am very ==boring==.（我是令人无聊的人）
> - ✅ I am very ==bored==.（我感到无聊）
> - ❌ The news was ==surprised==.
> - ✅ The news was ==surprising==.（消息令人惊讶）

## 副词的定义、分类与位置

- **副词**：表示时间、地点、程度、方式等概念的词
- **修饰对象**：动词、形容词、副词或==整个句子==
- **核心作用**：给动作、状态或整句话“加限定条件”

| 修饰对象 | 位置 | 例句 |
| :--- | :--- | :--- |
| 动词 | 动词之后 | He reads ==loudly==. |
| 副词 | 被修饰的副词之前 | He reads ==very== loudly. |
| 形容词 | 被修饰的形容词之前 | They are ==really== good books. |
| 整个句子 | 句首 | ==Actually==, they are really good books. |

### 副词的五大分类

| 类别 | 常见词 |
| :--- | :--- |
| 程度副词 | much、too、little、so、rather、very |
| 频率副词 | never、hardly、seldom、sometimes、often、usually、always |
| 时间副词 | now、then、early、today、soon、yesterday、tomorrow |
| 地点副词 | here、there、everywhere、anywhere、outside、inside |
| 方式副词 | quickly、loudly、largely、rapidly |

- **频率副词位置**：be/助动词之后、实义动词之前

例句：I have ==never== seen him.

（待确认：原稿括号内疑似“频率副词在时间副词前”，字迹模糊；按常规规则应为“频率副词在 be/助动词后、实义动词前”，请核对）

> [!why] 底层逻辑：为什么频率副词放在 be/助动词后、实义动词前？
> 频率副词（always、never）是对“整个动作发生频率”的评价，要紧贴它评价的动词。be 动词和助动词是句子的“骨架”，频率副词插在骨架之后、实义动词之前（I have ==never== seen him），既不破坏句子的主干，又正好站在它修饰的动词前面。

## 形容词变副词规则

| 规则 | 例词 |
| :--- | :--- |
| 一般情况直接 + ly | loud → ==loudly==、quick → ==quickly==、real → ==really== |
| 以 e 结尾，直接 + ly | wise → ==wisely== |
| 以 y 结尾，把 y 变 i 加 ly | lucky → ==luckily== |
| 以 le 结尾，去 e 加 y | simple → ==simply==、possible → ==possibly==、gentle → ==gently== |
| 以 ve 结尾，去 e 加 y | true → ==truly==、due → ==duly== |
| 以 ic 结尾，加 ally | basic → ==basically==、scientific → ==scientifically==、automatic → ==automatically== |
| 以 ll 结尾，去掉一个 l 加 y | full → ==fully==、dull → ==dully== |
| 特殊 | whole → ==wholly==、public → ==publicly==、dry → ==dryly==、shy → ==shyly== |

> [!why] 底层逻辑：-ly 是“像……的样子”，拼写变化只为读得顺
> -ly 本义是 like（像），加在形容词后表示“以……的方式”。拼写上的小变化（去 e、y 变 i、ic 加 ally）不是语义变化，只是为了让发音和拼写顺畅：true + ly 读着别扭，去掉 e 变成 truly 就顺了。

### 形副同形词

- **形副同形**：形容词与副词形式==完全相同==

| 词 | 形容词义 | 副词义 |
| :--- | :--- | :--- |
| early | 早的 | 早地 |
| hard | 难的 | 努力地 |
| fast | 快的 | 快地 |
| late | 晚的 | 晚地 |
| far | 远的 | 远地 |
| back | 回来的 | 向后 |

### 像副词的形容词

- **特征**：以 -ly 结尾，但仍是==形容词==

| 词 | 释义 |
| :--- | :--- |
| ugly | 丑陋的 |
| deadly | 致命的 |
| lonely | 孤独的 |
| friendly | 友好的 |
| lovely | 可爱的 |
| fatherly | 父亲般的 |
| lively | 活泼的 |
| daily | 每日的 |
| weekly | 每周的 |
| likely | 可能的 |

> [!trap] 考试易错坑：-ly 结尾不一定是副词
> 看到 -ly 就当副词是最常见的坑：friendly、lonely、lively、likely 都是形容词，不能修饰动词。
> - ❌ He speaks ==friendly==.
> - ✅ He is a ==friendly== man. / He speaks in a ==friendly== way.
> - **likely 固定搭配**：be ==likely== to do sth.（可能做某事）、be more ==likely== to do sth.（更可能做某事）

### good / well 与 enough

| 词 | 词性与含义 | 例句 |
| :--- | :--- | :--- |
| good | adj. 好的 | This is a ==good== book. |
| well | adj. 身体好的；健康的；adv. 好地；n. 井 | Are you ==well== today? / You can learn English ==well==. |
| enough | adj. 足够的；adv. 足够地 | I have ==enough== time. / She is not brave ==enough==. |

- **enough 的位置**：作副词时放在所修饰的形容词==之后==
- **句型**：形容词 + ==enough to do sth.==

（足够……去做……）例句：She is brave ==enough to face the truth==.

### too 的三个句型

| 句型 | 含义 | 例句 |
| :--- | :--- | :--- |
| too…to… | 太……而不能 | The boy is too ==young to go== to school. |
| cannot…too… | 再……也不为过 | You cannot be too ==careful==.（你再谨慎也不为过） |
| never too…to… | 活到老，学到老 | It is never too ==old to learn==. |

> [!why] 底层逻辑：为什么 cannot…too… 是“再……也不为过”？
> cannot 是否定“能够”，too 是“过分”：You cannot be too careful = “你不可能谨慎得过分”——再谨慎都不过分。否定 + 过分 = 肯定到极致，这是英语里“否定表强调”的固定套路。

| 词 | 词性与含义 | 例句 |
| :--- | :--- | :--- |
| alone | adj. 单独的；adv. 单独地 | I live ==alone==, but I don't feel lonely. |
| lonely | adj. 孤独的；荒凉的（可修饰人和物） | ==lonely== years（孤独的岁月）；a ==lonely== village（一个荒凉的村庄） |
| look like | 介词短语：A 像 B | Tom looks ==like== his father. |
| look alike | 形容词短语：A 和 B 相像 | Tom and his father look ==alike==. |

## 形容词与副词的原级比较

> [!formula] 原级比较句型公式
> - 前者 = 后者：as + adj./adv. 原级 + as
> - 前者 < 后者：not as/so + adj./adv. 原级 + as
> - 中间有名词 ①：as + adj. + a/an + 可数名词单数 + as
> - 中间有名词 ②：as + many/few + 可数名词复数 + as
> - 中间有名词 ③：as + much/little + 不可数名词 + as

| 句型 | 例句 |
| :--- | :--- |
| as…as（一样） | He is as ==strong== as the man.（他和那个男人一样强壮） |
| not as/so…as（不如） | （待确认：人名疑似 Su Bingtian）Su Bingtian isn't as/so ==strong== as Yao Ming. |
| as + adj. + a/an + 可数单数 | Tom is as ==good a student== as Mary. |
| as + many/few + 可数复数 | We read as ==many/few books== as they. |
| as + much/little + 不可数 | We did as ==much/little work== as they. |

> [!why] 底层逻辑：为什么 not as…as 里 not 否定的是谓语动词？
> as…as 表达的是“等同”，not as…as 否定的是整个“等同”关系。not 的位置在 be/助动词之后，否定的是整个谓语 "is as strong as"，意思是“没有达到一样强”，也就是“不如”。所以翻译时先按五大基本句型翻成正常句子，再把 as as 放到合适的位置。

> [!formula] 翻译步骤
> 1. 根据五大基本句型翻译成正常句子
> 2. 把 as as 放到合适的位置
> - 注意：第二个句型中 not 是对谓语动词的否定
