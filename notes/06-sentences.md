# 疑问句与句型

## 基本句型与句子成分

- **陈述句**：陈述事实，含肯定与否定形式
- **疑问句**：提出问题，含一般与特殊疑问句

> [!why] 底层逻辑
> 英文句子变疑问和否定的本质，是找一个“==功能性动词==”到主语前面（变疑问）或在其后加 `not`（变否定）。如果句中原本就有 `be` 动词、情态动词或助动词，直接用它；如果只有==实义动词==，就必须请 `do / does / did` 来当替身扛起人称和时态变化，原本的实义动词因此必须==还原为原形==。

### 五大基本句型

五大句型是所有英文句子的骨架，差别只在谓语后跟什么成分。判断时先看谓语动词是及物还是不及物，再看它后跟宾语、双宾语、宾补还是表语。

| 句型 | 结构 | 关键特征 | 例句 |
| :--- | :--- | :--- | :--- |
| ① 主谓 | 主语 + 谓语 | 谓语为==不及物动词==，不接宾语 | `You jump!` [🔊](https://raw.githubusercontent.com/AZEN-jc/muse-grammar-notes/main/assets/audio/sentences/you-jump.mp3) |
| ② 主谓宾 | 主语 + 谓语 + 宾语 | 谓语为==及物动词==，动作有承受者 | `I like cats.` [🔊](https://raw.githubusercontent.com/AZEN-jc/muse-grammar-notes/main/assets/audio/sentences/i-like-cats.mp3) |
| ③ 主谓双宾 | 主语 + 谓语 + 间接宾语 + 直接宾语 | 间接宾语指人，直接宾语指物 | `I give you a gift.` [🔊](https://raw.githubusercontent.com/AZEN-jc/muse-grammar-notes/main/assets/audio/sentences/i-give-you-a-gift.mp3) |
| ④ 主谓宾宾补 | 主语 + 谓语 + 宾语 + 宾补 | 宾补补充说明==宾语== | `This gift makes me happy.` [🔊](https://raw.githubusercontent.com/AZEN-jc/muse-grammar-notes/main/assets/audio/sentences/this-gift-makes-me-happy.mp3) |
| ⑤ 主系表 | 主语 + 系动词 + 表语 | 表语说明==主语==的性质或身份 | `I am a teacher.` |

> [!formula] 五大基本句型公式
> - ① 主谓：`S + V`（V 为不及物动词）
> - ② 主谓宾：`S + V + O`（V 为及物动词）
> - ③ 主谓双宾：`S + V + ==IO== + ==DO==`（间人直物）
> - ④ 主谓宾宾补：`S + V + O + ==OC==`
> - ⑤ 主系表：`S + ==系动词== + P`

#### ① 主谓结构

- **主语**：一般位于谓语动词前，常由名词、代词充当
- **谓语**：说明主语干什么、怎么样
- **例句**：`You ==jump==!` [🔊](https://raw.githubusercontent.com/AZEN-jc/muse-grammar-notes/main/assets/audio/sentences/you-jump.mp3) / `I ==jump==!` [🔊](https://raw.githubusercontent.com/AZEN-jc/muse-grammar-notes/main/assets/audio/sentences/i-jump.mp3)

常见不及物动词：`go` `come` `happen` `listen` `rise` `arrive` `stay` `live` `talk` `work`

> [!why] 底层逻辑：不及物动词为什么不能直接加宾语？
> 不及物动词的动作“到此为止”，没有承受者；想带宾语必须请==介词==搭桥，介词 + 宾语整体作==状语==，动词本身仍是不及物：`I jump ==into== the river.`（`into the river` 是状语，不是宾语）。

> [!trap] 考试易错坑：不及物动词直接加宾语
> - ❌ `I jump the river.`
> - ✅ `I jump ==into== the river.`

#### ② 主谓宾结构

- **宾语**：动作的承受者，常由名词、代词充当
- **例句**：`I like ==cats==.`

常见及物动词：`do` `read` `visit` `spend` `say`

#### ③ 主谓双宾结构

- **间接宾语**：动作的接受者，指==人==
- **直接宾语**：动作的承受物，指==物==
- **例句**：`I give ==you== a gift.`

> [!mnemonic] 记忆口诀：间人直物
> 间接宾语指==人==，直接宾语指==物==：`give ==you==（人） a gift（物）`。

常见后跟双宾语的动词：

| 动词 | 结构 | 释义 |
| :--- | :--- | :--- |
| give | `give sb. sth.` | 给某人某物 |
| tell | `tell sb. sth.` | 告诉某人某事 |
| send | `send sb. sth.` | 寄给某人某物 |
| show | `show sb. sth.` | 给某人看某物 |
| ask | `ask sb. sth.` | 问某人某事 |
| bring | `bring sb. sth.` | 给某人带来某物 |
| buy | `buy sb. sth.` | 给某人买某物 |
| teach | `teach sb. sth.` | 教某人某事 |

> [!trap] 考试易错坑：双宾语语序不能颠倒
> - ❌ `I give a gift you.`
> - ✅ `I give ==you== a gift.`

#### ④ 主谓宾宾补结构

- **宾语补足语**：对宾语补充说明，常由形容词、名词充当
- **例句**：`This gift makes ==me== ==happy==.`

常见后跟宾补的动词：

| 动词 | 结构 | 释义 |
| :--- | :--- | :--- |
| find | `find sb/sth ...` | 发现某人某物…… |
| think | `think sb/sth ...` | （待确认：疑似“认为某人某物……”） |
| believe | `believe sb/sth ...` | （待确认：疑似“相信某人某物……”） |
| consider | `consider sb/sth ...` | 认为某人某物…… |
| make | `make sb/sth ...` | 使某人某物…… |
| call | `call sb/sth ...` | 把某人某物叫作…… |

> [!why] 底层逻辑：宾补和表语有什么区别？
> 看补充说明的对象：宾补说明==宾语==（`makes ==me== happy`——`happy` 说的是 `me`），表语说明==主语==（`I am a ==teacher==`——`teacher` 说的是 `I`）。位置不同、对象不同，别混用。

#### ⑤ 主系表结构

- **表语**：说明主语的性质、特征、状态或者身份
- **表语常由**：形容词和名词充当
- **例句**：`I am ==a teacher==.`

### 修饰成分概念

| 修饰成分 | 定义 |
| :--- | :--- |
| 状语 | 说明地点、时间、原因、目的、结果、条件、方向、程度、方式和伴随状况等 |
| 定语 | 修饰或限定名词或代词的句子成分 |
| 同位语 | 解释或补充说明前面名词、代词的情况，是对前面名/代词内容的更具体展现 |

> [!why] 底层逻辑：状语、定语、同位语怎么分？
> 看修饰的对象：定语管==名词==（哪个、什么样的）；状语管==动词或整个句子==（何时、何地、为何、如何）；同位语是把前面的名词==换个说法再说一遍==，与它指同一人或物。

> [!trap] 考试易错坑：定语 vs 同位语
> 定语是==限定==（回答“哪一个”），同位语是==等同说明==（回答“具体是谁 / 是什么”），两者都跟在名词后，判断时看后者与前者是否指同一事物。

## 四大疑问句详解

### 一般疑问句 vs 特殊疑问句

| 句型 | 结构特征 | 回答方式 | 例句 |
| :--- | :--- | :--- | :--- |
| 一般疑问句 | `be` / 情态 / 助动词提前 | 用 ==Yes / No== 回答 | `Are you a student?` |
| 特殊疑问句 | ==特殊疑问词==开头 | 回答具体信息（不用 Yes/No） | `When does he go to school?` |

### 一般疑问句与否定句变换规则

| 谓语构成 | 一般疑问句变法 | 否定句变法 | 例句转换 |
| :--- | :--- | :--- | :--- |
| 含情态动词 / 助动词 | 将其提至==句首== | 在其后加 ==not== | `He can swim.` → `Can he swim?` / `You can't swim.` |
| 单独 `be` 动词作谓语 | 将 `be` 提至==句首== | 在 `be` 后加 ==not== | `You are a student.` → `Are you a student?` |
| 单独实义动词作谓语 | 句首加 ==Do/Does/Did==，动词还原 | 动词前加 ==don't/doesn't/didn't==，动词还原 | `She likes reading.` → `Does she like reading?` / `She doesn't like reading.` |

#### 常见否定缩写速查表

| 词类 | 原形 + `not` | 标准缩写形式 | 注意事项 |
| :--- | :--- | :--- | :--- |
| 情态动词 | `can not` / `must not` / `should not` | `can't` / `mustn't` / `shouldn't` | `may not` 通常==不缩写== |
| 助动词 | `will not` / `have not` / `has not` | `won't` / `haven't` / `hasn't` | 注意 `will not` 缩写为 `won't` |
| `be` 动词 | `is not` / `are not` / `was not` / `were not` | `isn't` / `aren't` / `wasn't` / `weren't` | `am not` 无通用标准缩写（`I'm not`） |

### 特殊疑问词全表

| 疑问词 | 核心提问对象 | 常见句法角色 / 备注 |
| :--- | :--- | :--- |
| `what` | 什么 | 问事物、职业、动作或内容 |
| `who` | 谁 | 作==主语==或表语 |
| `whom` | 谁 | 作==宾语==（口语常可用 `who` 替代） |
| `whose` | 谁的 | 问所属关系（后可接名词） |
| `which` | 哪一个 | 强调在==一定范围==内选择 |
| `when` | 何时 | 问时间点或时间段 |
| `where` | 哪里 | 问地点 |
| `why` | 为什么 | 问原因 |
| `how` | 如何，怎样 | 问方式、程度或健康状况 |

#### `how` 派生高频疑问词组

| 疑问词组 | 提问对象 | 关键搭配规则 |
| :--- | :--- | :--- |
| `how many` | 数量（多少） | `+ ==可数名词复数==` |
| `how much` | 数量（多少） / 价格 | `+ ==不可数名词==` |
| `how long` | 时间长度（多久） / 物体长度（多长） | 回答常用 `for + 时间段` |
| `how far` | 距离（多远） | 问两地距离 |
| `how often` | 频率（多久一次） | 回答常用 `once a week` 等 |

### 特殊疑问句两大语序公式

> [!formula] 特殊疑问句语序公式
> 1. **疑问词作主语**（语序不变）：`疑问词 + 谓语 + 其他？`
>    - 例：`==Who== is your teacher?`
> 2. **疑问词不作主语**（必须倒装）：`疑问词 + ==一般疑问语序==？`
>    - 转换示范：`He goes to school at 7:00.`
>    - → 一般疑问：`Does he go to school at 7:00?`
>    - → 否定句：`He doesn't go to school at 7:00.`
>    - → 特殊疑问：`When ==does he go== to school?`

> [!trap] 高频易错点
> 用 `Does / Did` 提问或 `doesn't / didn't` 否定时，后面的实义动词一定要==退回原形==（如 `likes → like`，`goes → go`），切忌写成 `Does he goes...`！

### 反意疑问句避坑要点

- **核心原则**：前肯后否、前否后肯，主谓时态一致

> [!trap] 考试易错坑：反意疑问句“隐性否定词”与特殊祈使句
> - 陈述部分含 `hardly / seldom / rarely / few / little / never / nothing` 等==半否定/否定词==时，视为**前否**，附加问句必须用==肯定==（如 `He seldom goes out, ==does he==?`）。
> - `Let's ...` 附加问句用 ==shall we==；`Let us ...` 及其他祈使句用 ==will you==。

## 感叹句与祈使句

- **感叹句核心**：去主谓后看中心词是==名词==还是==形/副==

> [!mnemonic] 感叹句 `What` vs `How` 速记口诀
> - **去主谓、看尾词：形名相连用 `What`，形副独立用 `How`。**
> - 例：`==What== a fine day it is!`（尾词为名词 `day`）/ `==How== fine the day is!`（尾词为形容词 `fine`）。
> - 不可数名词与复数名词前不加 `a/an`：`==What== useful advice it is!`
