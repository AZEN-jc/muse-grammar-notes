# 疑问句与句型

## 基本句型与句子成分

- **陈述句**：陈述事实，含肯定与否定形式
- **疑问句**：提出问题，含一般与特殊疑问句

> [!why] 底层逻辑
> 英文句子变疑问和否定的本质，是找一个“==功能性动词==”到主语前面（变疑问）或在其后加 `not`（变否定）。如果句中原本就有 `be` 动词、情态动词或助动词，直接用它；如果只有==实义动词==，就必须请 `do / does / did` 来当替身扛起人称和时态变化，原本的实义动词因此必须==还原为原形==。

## 四大疑问句详解

### 一般疑问句 vs 特殊疑问句

| 句型 | 结构特征 | 回答方式 | 例句 |
| :--- | :--- | :--- | :--- |
| 一般疑问句 | `be` / 情态 / 助动词提前 | 用 ==Yes / No== 回答 | `Are you a student?` |
| 特殊疑问句 | ==特殊疑问词==开头 | 回答具体信息（不用 Yes/No） | `When does he go to school?` |

### 一般疑问句与否定句变换规则

| 谓语构成 | 一般疑问句变法 | 否定句变法 | 例句转换 |
| :--- | :--- | :--- | :--- |
| 含情态动词 / 助动词 | 将其提至==句首== | 在其后加 ==not== | `He can swim.` → `Can he swim?` / `You can't swim.` |
| 单独 `be` 动词作谓语 | 将 `be` 提至==句首== | 在 `be` 后加 ==not== | `You are a student.` → `Are you a student?` |
| 单独实义动词作谓语 | 句首加 ==Do/Does/Did==，动词还原 | 动词前加 ==don't/doesn't/didn't==，动词还原 | `She likes reading.` → `Does she like reading?` / `She doesn't like reading.` |

#### 常见否定缩写速查表

| 词类 | 原形 + `not` | 标准缩写形式 | 注意事项 |
| :--- | :--- | :--- | :--- |
| 情态动词 | `can not` / `must not` / `should not` | `can't` / `mustn't` / `shouldn't` | `may not` 通常==不缩写== |
| 助动词 | `will not` / `have not` / `has not` | `won't` / `haven't` / `hasn't` | 注意 `will not` 缩写为 `won't` |
| `be` 动词 | `is not` / `are not` / `was not` / `were not` | `isn't` / `aren't` / `wasn't` / `weren't` | `am not` 无通用标准缩写（`I'm not`） |

### 特殊疑问词全表

| 疑问词 | 核心提问对象 | 常见句法角色 / 备注 |
| :--- | :--- | :--- |
| `what` | 什么 | 问事物、职业、动作或内容 |
| `who` | 谁 | 作==主语==或表语 |
| `whom` | 谁 | 作==宾语==（口语常可用 `who` 替代） |
| `whose` | 谁的 | 问所属关系（后可接名词） |
| `which` | 哪一个 | 强调在==一定范围==内选择 |
| `when` | 何时 | 问时间点或时间段 |
| `where` | 哪里 | 问地点 |
| `why` | 为什么 | 问原因 |
| `how` | 如何，怎样 | 问方式、程度或健康状况 |

#### `how` 派生高频疑问词组

| 疑问词组 | 提问对象 | 关键搭配规则 |
| :--- | :--- | :--- |
| `how many` | 数量（多少） | `+ ==可数名词复数==` |
| `how much` | 数量（多少） / 价格 | `+ ==不可数名词==` |
| `how long` | 时间长度（多久） / 物体长度（多长） | 回答常用 `for + 时间段` |
| `how far` | 距离（多远） | 问两地距离 |
| `how often` | 频率（多久一次） | 回答常用 `once a week` 等 |

### 特殊疑问句两大语序公式

> [!formula] 特殊疑问句语序公式
> 1. **疑问词作主语**（语序不变）：`疑问词 + 谓语 + 其他？`
>    - 例：`==Who== is your teacher?`
> 2. **疑问词不作主语**（必须倒装）：`疑问词 + ==一般疑问语序==？`
>    - 转换示范：`He goes to school at 7:00.`
>    - → 一般疑问：`Does he go to school at 7:00?`
>    - → 否定句：`He doesn't go to school at 7:00.`
>    - → 特殊疑问：`When ==does he go== to school?`

> [!trap] 高频易错点
> 用 `Does / Did` 提问或 `doesn't / didn't` 否定时，后面的实义动词一定要==退回原形==（如 `likes → like`，`goes → go`），切忌写成 `Does he goes...`！

### 反意疑问句避坑要点

- **核心原则**：前肯后否、前否后肯，主谓时态一致

> [!trap] 考试易错坑：反意疑问句“隐性否定词”与特殊祈使句
> - 陈述部分含 `hardly / seldom / rarely / few / little / never / nothing` 等==半否定/否定词==时，视为**前否**，附加问句必须用==肯定==（如 `He seldom goes out, ==does he==?`）。
> - `Let's ...` 附加问句用 ==shall we==；`Let us ...` 及其他祈使句用 ==will you==。

## 感叹句与祈使句

- **感叹句核心**：去主谓后看中心词是==名词==还是==形/副==

> [!mnemonic] 感叹句 `What` vs `How` 速记口诀
> - **去主谓、看尾词：形名相连用 `What`，形副独立用 `How`。**
> - 例：`==What== a fine day it is!`（尾词为名词 `day`）/ `==How== fine the day is!`（尾词为形容词 `fine`）。
> - 不可数名词与复数名词前不加 `a/an`：`==What== useful advice it is!`
